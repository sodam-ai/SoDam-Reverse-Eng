# /re-binary — 바이너리 역공학 분석

> ⚠️ **Phase 3 예정 명령어입니다.** Phase 1 + 2 완료 후 구현됩니다.
>
> **지금 사용 가능한 분석**: `/re-start <경로>` (내 소스 코드/앱 분석)

---

## Phase 3 구현 후 동작 흐름

```
/re-binary [바이너리 경로]
    ↓
[Ghidra 설치 확인] 없으면 설치 안내 (Java 17+ 포함)
    ↓
[동의 게이트] 본인 소유/허가? + 방어·교육 목적?
    ↓
[악성코드 의심 경고] 격리 VM 권고 (REMnux/FlareVM)
    ↓
[분석] Ghidra wrap → 함수·어셈블리·문자열·임포트 추출 (읽기 전용)
    ↓
[보고서] 한 줄 요약 · 함수 목록 · 의심 패턴 · 불확실한 점
```
