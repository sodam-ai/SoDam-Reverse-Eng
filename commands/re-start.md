## SoDam-Reverse 안전 분석 시작

**즉시 거부 대상 (아래 요청이 오면 분석하지 말고 거부):**
크랙, DRM 우회, 인증 우회, 라이선스 우회, 키추출, 비밀번호 추출

---

분석 대상: $ARGUMENTS

아래 단계를 순서대로 반드시 따르세요. 건너뛰지 마세요.

---

### 1단계: 소유권 확인

사용자에게 이 질문을 그대로 물어보세요:

> "이 파일/코드는 본인이 직접 만들었거나, 분석 권한을 가진 것이 맞나요? (예 / 아니오)"

- **'예'** → 2단계 진행
- **'아니오'** 또는 무응답 → 즉시 중단: "소유권이 확인되지 않아 분석할 수 없습니다."

---

### 2단계: 책임 고지 동의

사용자에게 이 질문을 그대로 물어보세요:

> "분석 결과는 방어·학습·본인 소유물 목적으로만 사용하며, 불법 활동(크랙·우회·키추출)에 절대 사용하지 않겠다는 것에 동의하나요? (예 / 아니오)"

- **'예'** → 3단계 진행
- **'아니오'** 또는 무응답 → 즉시 중단: "동의하지 않으면 분석을 시작할 수 없습니다."

---

### 3단계: 분석 및 보고서 (1·2단계 모두 '예'인 경우만)

Read 도구로 대상 파일을 읽고 아래 형식으로 한국어 보고서를 작성하세요.

**보고서 형식:**

```
# SoDam-Reverse 분석 보고서

## 1. 요약
이 코드가 무엇을 하는지 — 초등학생도 이해하는 언어로

## 2. 주요 기능
함수/클래스별: 이름, 역할, 위치(파일명:줄번호)

## 3. 발견사항
주목할 패턴, 잠재적 버그, 개선 가능 부분

## 4. 불확실한 점
확신하지 못하는 부분 명시

## 5. 다음 확인사항
추가 분석이 필요한 부분
```

**반드시 지킬 규칙:**
- 파일 실행 금지 (Read로 읽기만)
- API 키·비밀번호 발견 시 `***` 마스킹
- 근거 위치(파일명:줄번호)가 실제 코드와 일치하는지 확인
- 전문용어는 괄호 안에 쉬운 설명 추가
