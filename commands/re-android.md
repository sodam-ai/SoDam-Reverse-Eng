# /re-android — 안드로이드 APK 분석

> ⚠️ **Phase 2 예정 명령어입니다.** 현재 사용 불가.
>
> **지금 사용 가능한 분석**: `/re-start <경로>` (내 소스 코드/앱 분석)
>
> Phase 2 예정 시기: Phase 1 마켓 배포 및 안정화 완료 후

---

## Phase 2 구현 후 동작 흐름

```
/re-android [APK 경로]
    ↓
[외부 도구 확인] JADX · Apktool 설치 여부
    ↓
[동의 게이트] 본인 소유/허가 APK? + 방어·교육 목적?
    ↓
[분석] APK → 디컴파일 → 구조·API·URL·퍼미션 추출 (읽기 전용)
    ↓
[보고서] 한 줄 요약 · 구조·퍼미션 · API/URL 목록 · 불확실한 점
    ↓
[저장] .sodam-re/android/ 로컬 전용
```
