`re-report` 스킬을 사용해 분석 결과를 표준 한국어 보고서로 출력하세요.

세션 id(있으면): $ARGUMENTS

지켜야 할 것:
- 형식 고정: 요약 · 함수별 설명 · 근거 위치 · 불확실한 점 · 다음 확인사항 · 안전
- 근거 위치(파일:라인)가 **실제 코드와 일치**하는지 확인 (정확성 게이트). 단, 원본 파일은 이번 대화에서 그 대상의 안전장치 자가검증 통과와 동의가 있었을 때만 열고, 없으면 `re-router`의 0-A부터 진행하거나 "대조하지 못함"으로 적기
- 분석 중 발견한 시크릿은 **마스킹**
